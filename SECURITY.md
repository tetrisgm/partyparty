# Security policy

PartyParty turns a Mac into a network server and treats security reports
seriously.

Please do not open a public issue for a vulnerability or include credentials,
private party URLs, logs containing guest information, or other sensitive data
in a report. Email [support@partyparty.party](mailto:support@partyparty.party)
with a concise description, affected version, reproduction steps, and impact.

The project owner will acknowledge a report as soon as practical, investigate
it, and coordinate disclosure after a fix is available. There is currently no
bug bounty program.

Only the current TestFlight build and the version served by
[partyparty.party](https://partyparty.party) receive security support.
