Advanced settings
Plain HLS is the default and plays on any phone with no cert. Low latency (LL-HLS) needs a real HTTPS cert; switching restarts the broadcast.
Lower latency = less buffer, so it's more sensitive to drops. If audio cuts out on a weak network, step toward Stable.
“Capture the Mac’s output” needs Screen Recording permission the first time. It captures everything playing — turn on Do Not Disturb so notification sounds don’t go out.
Not sure it works? Pick Test tone and Start — if a guest hears the beep, your network path is good and you only need to fix the audio routing.
How do I capture my sound?

① Capture everything on the Mac (easiest)

Pick 🖥️ Capture the Mac’s output and Start. Grant Screen Recording permission once when asked, then Stop/Start. No driver, no routing — it grabs whatever is playing (RekordBox, Spotify, etc.). Turn on Do Not Disturb so notification dings don’t go out.

② Capture only one app (e.g. RekordBox), no system sounds

Install brew install blackhole-2ch. Set RekordBox → Preferences → Audio → Output → BlackHole 2ch (or a Multi-Output Device incl. BlackHole so you still hear it), then pick BlackHole above.

③ Hardware controller / mixer

Route the controller’s REC / USB record output to the Mac and select that device above. (Pioneer: set a USB out to MIX/REC OUT.) Or run its REC/booth out into an audio interface input and pick the interface.

Keep everything at 48 kHz to avoid clicks.
