HOLD-BACK IS A LEVER: declaring it moves where AVPlayer attaches, by about the amount declared.
The shipping media playlist declares PART-HOLD-BACK but NO HOLD-BACK, so the room inherits the
HLS default of three target durations. gohlslib rounds TARGETDURATION to an integer second, so
that default is 3 x 1s = 3s. The room's declared three-second cushion is a
coincidence of that rounding, not something the code asks for, and it would move on its own if
the segment duration ever changed.
The 1.5s arm did not play at all, which is the HLS floor asserting itself: HOLD-BACK below three
target durations (3s here) is invalid, and AVPlayer refuses the playlist outright rather
than holding back less. HOLD-BACK can lengthen the cushion. It cannot shorten it below that floor.
relay transport floor on loopback: edge 0.27s, attach 2.81s.
A venue adds wide-area delay on top of that edge; it never reduces it.
