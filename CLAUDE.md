# partyparty: working notes

Read and follow `AGENTS.md`. Shared build and delivery behavior is owned by the
`workshop-delivery` skill and `workshop delivery`; do not restate or fork it
here. PartyParty has two intentional release channels: the settled standalone
beta controller and an explicitly dispatched App Store workflow.

Read `AGENTS.md`, `codex/PLAN.md`, and `codex/HANDOFF.md` before changing this
project. PartyParty is account-free. Do not add product authentication, cloud
party pages, or any release path beyond the two documented channels.
